# 终端工具接入设计

日期：2026-09-03

状态：实施及验证完成；排除 mpv，未提交或推送。

## 目标与边界

沿用当前模块化 Zsh 配置，接入 radleylewis/zsh 的指定命令行功能，使用 Yazi 替代 lf。只修改本次功能涉及的文件，不覆盖个人配置。

- Neovim 已安装时直接复用；增加交互式别名 `vim='nvim'`。
- 保留 `EDITOR='code --wait'` 和 `VISUAL='code --wait'`，不更改默认编辑器，不覆盖 Vim 可执行文件。
- 安装缺少的 eza、Yazi；复用已安装的 bat、ripgrep、fd、fzf、zoxide 和 Neovim。
- 不安装或配置 mpv、lf，不添加摄像头 stream 别名，不访问摄像头。
- 保留现有 Starship、Git 别名状态、Zsh 插件和 Emacs 按键模式。
- 保留 Homebrew、Conda、Proto、Cargo、Bun、OrbStack、代理和个人辅助函数。
- 不提交、推送、部署，不升级无关软件，不强制重载用户已经打开的终端。

## 配置方案

| 工具 | 行为 |
| --- | --- |
| Neovim | `vim` 调用 `nvim`；默认编辑器继续为 VS Code |
| eza | `ls` 显示图标；`ll`、`la` 显示详细信息和 Git 状态；`tree` 显示树形目录 |
| bat | `cat` 指向 bat；使用 bat 阅读 man 页；作为 fzf 文件预览器 |
| ripgrep | `grep` 指向 `rg --color=auto` |
| fd | 为 fzf 生成文件列表；默认包含隐藏文件，保留 fd 的忽略规则 |
| fzf | `Ctrl+R` 搜索历史；`Ctrl+T` 选择含隐藏文件的文件列表；`Ctrl+F` 选择不含隐藏文件的文件列表 |
| zoxide | 启动时初始化，提供 `z` 智能跳转；不替换 `cd` |
| Yazi | 提供 `y` Shell 函数；退出后切换到其最终目录；不设置 `lf` 别名 |

fzf 沿用上游的反向列表、圆角边框、60% 高度、右侧预览等界面设置；bat 预览文件前 500 行并显示行号。实现时核对当前上游和本机 fzf 的接口。

`Ctrl+T` 和 `Ctrl+F` 将分别覆盖当前的交换字符和光标右移行为；不引入上游的 zsh-vi-mode、历史子串搜索插件或其他未请求快捷键。

Yazi 使用默认界面及现有默认编辑器，不引入主题或第三方插件。只安装主程序及包管理器必须依赖，不批量安装官方文档列出的可选预览依赖；视频、PDF 等预览是否可用以已有依赖和实际验证为准。

## 实现位置与兼容处理

- `aliases.zsh`：命令别名及 Yazi 目录跟随函数。
- `fzf.zsh`：fzf 初始化、fd 文件列表、bat 预览和额外文件选择组件。
- `bindings.zsh`：本次要求的额外按键绑定；绑定顺序确保组件已定义。
- `.zshrc`：按需调整模块加载顺序，初始化 zoxide、设置 man 阅读器；保留编辑器与其他环境设置。
- `README.md`：记录安装依赖、快捷键、行为差异和恢复方法。

补全定义必须在 compinit 可用后执行，语法高亮保持在相关交互组件加载后接入；不替换插件种类或更新插件版本。

工具不可用时不创建失效别名或执行不存在的初始化命令。用于程序内部读取原始文本的地方不得因 `cat` 别名获得分页、高亮或行号输出。fzf 选中文件插入命令行时正确转义空格和特殊字符。

Yazi 的目录跟随使用独立临时文件，正确引用目录，退出取消、空输出或目录不存在时保持当前目录不变。只删除该调用创建的临时文件。

交互式 `grep` 别名不是 GNU/BSD grep 的逐选项兼容替换；需要原始命令时使用 `command grep`。同理可使用 `command cat`、`command ls`、`command vim` 绕过本次别名。

## 备份与验证

实施前把将要修改的实际文件复制到一个独立、带时间标识的备份目录，并记录其位置。若发现新的未提交改动，先核对冲突，保留用户修改。

验收包括：

1. 核对依赖命令路径与版本，确认未安装 mpv、lf，也未升级无关软件。
2. 对修改的 Shell 文件执行语法检查和 `git diff --check`。
3. 在新建的交互式登录 Zsh 中核对别名、工具初始化、补全和快捷键；使用正常终端类型，避免测试环境的 TERM=dumb 干扰。
4. 明确断言 EDITOR、VISUAL 仍为 `code --wait`；Starship 与现有三种插件保持加载。
5. 用临时样例文件验证文件列表、隐藏文件规则、bat 输出及带空格路径；不编辑或删除用户业务文件。
6. 验证 Yazi 目录跟随和取消行为；区分自动测试结果与真实交互界面验证，不把模拟调用当作完整体验验收。
7. 检查最终差异，交付备份位置和加载方式；不自动提交或推送。

恢复时只还原本次变更的配置文件，不删除既有工具、配置目录或用户数据。
